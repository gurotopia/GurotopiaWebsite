# Linux Installation

This guide covers installing Gurotopia on various Linux distributions.

## Prerequisites

You'll need a terminal and sudo/root access to install dependencies. You also need a running
**MariaDB** server. The packages below are the compiler, OpenSSL, and the MariaDB *client* library
used to link `main.out`.

## Install Dependencies

Choose your distribution and run the appropriate commands:

### Arch Linux

```bash
sudo pacman -S base-devel openssl mariadb-libs
```

### Debian / Ubuntu

```bash
sudo apt-get update && sudo apt-get install build-essential libssl-dev libmariadb-dev
```

### Fedora

```bash
sudo dnf group install development-tools
sudo dnf install openssl-devel mariadb-connector-c-devel
```

<Callout type="info">
  `base-devel` / `build-essential` / `development-tools` include GCC, G++, and Make. Gurotopia
  needs **GCC 13 or newer** for `std::format`. See the [FAQ](/faq/build-errors) if the compiler
  rejects it.
</Callout>

## Clone the Repository

```bash
git clone https://github.com/gurotopia/Gurotopia.git
cd Gurotopia
```

## Compile the Server

Navigate to the project's root directory and run:

```bash
make -j$(nproc)
```

<Callout type="info">
  The `-j$(nproc)` flag uses all available CPU cores for faster compilation.
</Callout>

<Callout type="warn">
  Got a build error? Visit the [FAQ](/faq/build-errors) section, it might have the solution you
  need!
</Callout>

### Build Output

After successful compilation, you'll find the executable in the project directory:

```
./main.out
```

## Run the Server

Execute the compiled binary:

```bash
./main.out
```

The server will start and display connection information in the terminal.

### Run in Background

To run the server in the background:

```bash
nohup ./main.out > server.log 2>&1 &
```

Or use `screen` or `tmux` for a persistent session:

```bash
screen -S gurotopia
./main.out
# Press Ctrl+A, then D to detach
```

## Using Docker

Gurotopia also supports Docker for containerized deployment:

```bash
# Build the image
docker build -t gurotopia .

# Run the container
docker run -d -p 17091:17091 --name gurotopia-server gurotopia
```

<Callout type="warn">
  Make sure to configure your hosts file before connecting. See the
  [Configuration](/configuration) guide.
</Callout>

## Troubleshooting

### Permission denied

Make the binary executable:

```bash
chmod +x main.out
```

### Missing libraries

If you get "library not found" errors, install the OpenSSL and MariaDB client packages:

```bash
# Debian/Ubuntu
sudo apt-get install libssl-dev libmariadb-dev

# Arch
sudo pacman -S openssl mariadb-libs

# Fedora
sudo dnf install openssl-devel mariadb-connector-c-devel
```

### Port already in use

Check if another process is using the port:

```bash
sudo lsof -i :17091
```

Kill the process or change the port in configuration.
